New in session 2 · 2026-10-16

Sign-up returned an HTTP 504, which led to Google-only sign-in. Three lessons cover it: L2.07c (build it), L3.06 (OAuth, PKCE and the 504 under the hood) and L4.09 (testing it, and running the incident). The email-code sign-in in L2.07a is now history; its AuthProvider is still current.

The app you will rebuild

Live at psychology-of-learning-nptel.vercel.app: 130 assignment questions as swipeable flashcards, a quiz, a searchable list, a timed 100-question ranked test graded on the server, and a leaderboard, on every screen from a folded Galaxy phone to a 1920 px monitor, with one-tap Google sign-in. These pages walk through every file of it, why each line is there, the 40-odd real bugs that happened while building and running it, and the tests that now keep them fixed.

How to study this

The loop, for every lesson. It is built for recall, not for reading.

  1. Warm-up (2 min): answer the questions from earlier lessons before reading on. Wrong is fine; trying is the point.
  2. Read and predict: wherever an order ticket says Predict, stop and guess before you reveal.
  3. Run things: every command in "Running and testing" works on the real repository.
  4. Check yourself, then practise (easy → hard).
  5. From memory: the cloze, then the blank-page drill with no scrolling up. Tick the self-check honestly.
  6. Flashcards: answer aloud before you reveal; grade Forgot / Hard / Knew it.
  7. Reviews: the plan brings each lesson back 1, 3, 7 and 14 study days later for 10 minutes.

Prerequisites: skip what you know

Tick what you already know. Everything else is taught from zero in the lesson it links to.

Installs (all free)

Node 20+ (the project was built on Node 24), Git, Chrome or Edge, VS Code; later npx playwright install for the test browsers and Poppler or Xpdf for pdftotext.

A Supabase account and a Vercel account are needed only to deploy your own copy; every test except the live ones runs without them.

Reading conventions. Diagrams are drawn for this series; every box on the map below links to its lesson. Maths is typeset. Answers, hints and long source listings sit behind reveals: open them only when you've tried.
