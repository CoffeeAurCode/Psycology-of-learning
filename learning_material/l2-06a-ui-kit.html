The UI kit: sheets, switches, segmented control, rings, confetti

Recipe card75 min
You need
L2.05 (AnimatePresence, layoutId)
You'll produce
src/components/Ui.tsx (242 lines): Wordmark, Splash, Loader, Sheet, Switch, Segmented<T>, CountUp, Ring, BeanBurst, Toast, useToast, avatarColor, initials

In two sentences: Every page reuses these small components. The bottom sheet is used for confirmations and grids, the segmented control for modes and themes, and the ring and count-up for the score. They are where the app's polish lives, and each hides a small piece of maths or accessibility you should be able to rebuild.

By the end, without notes, you can

  1. Build a bottom sheet that opens with a spring, closes on Escape, scrim tap or a downward drag, and locks page scrolling while open.
  2. Build accessible toggles: role="switch" + aria-checked, and role="tablist"/tab + aria-selected.
  3. Derive the ring's strokeDasharray/strokeDashoffset from radius and progress, and the count-up's ease-out-cubic curve.
  4. Explain how avatarColor turns a name into a stable colour, and trace initials.

2

The problem this solves

Phones need native-feeling controls: sheets that slide up from the bottom (near the thumb), toggles, segmented pickers, and rewarding feedback when you finish a test. Building them once, accessibly, keeps every page consistent.

3

Concepts new in this lesson

3.1 Drawing a progress ring with stroke dashes

An SVG circle's outline can be drawn as dashes. Set the dash length to the full circumference C, so one dash covers the whole circle. Then shift it with an offset: offset C hides it entirely, and offset 0 shows it all.

With canvas size S and stroke width w, the circle must fit inside the canvas, so its radius is

r=2S−w​,C=2πr.

For a progress value v∈[0,1] (score / total), the visible part should be vC, so the hidden part (the offset) is

offset(v)=C(1−v).

Real numbers (the results ring): S=190, w=14 gives r=88, C=2π⋅88≈552.92. A score of 87/100 gives offset =552.92×0.13≈71.88. Motion animates the offset from 552.92 (empty) down to 71.88.

SVG starts a circle's stroke at 3 o'clock, so the whole SVG is rotated -90deg to start at 12 o'clock.

3.2 Easing: ease-out cubic

Animating a number linearly feels mechanical. Ease-out starts fast and settles. With progress p∈[0,1] (elapsed time ÷ duration),

e(p)=1−(1−p)3,n(t)=round(to⋅e(p)).
p e(p) shown for to = 87
0 0 0
0.25 0.578 50
0.5 0.875 76
0.75 0.984 86
1 1 87

Half the time covers 87.5% of the distance; the last quarter only creeps from 86 to 87. That is the "settling" feel.

3.3 requestAnimationFrame

requestAnimationFrame(cb) calls cb(timestamp) just before the next screen repaint (about 60 times a second), and never in hidden tabs. It is the right clock for visual animation. The timestamp is a high-resolution time in milliseconds, the same clock as performance.now().

4.2 Sheet (lines 33–72)

TSX40 lines
/** Bottom sheet (drag down or tap the scrim to close). */export function Sheet({ open, onClose, children }: { open: boolean; onClose: () => void; children: ReactNode }) {  useEffect(() => {    if (!open) return;    const k = (e: KeyboardEvent) => e.key === "Escape" && onClose();    window.addEventListener("keydown", k);    const prev = document.body.style.overflow;    document.body.style.overflow = "hidden";    return () => {      window.removeEventListener("keydown", k);      document.body.style.overflow = prev;    };  }, [open, onClose]);   return (    <AnimatePresence>      {open && (        <>          <motion.div className="scrim" onClick={onClose} initial={{ opacity: 0 }} animate={{ opacity: 1 }} exit={{ opacity: 0 }} />          <motion.div            className="sheet"            role="dialog"            aria-modal="true"            initial={{ y: "100%", x: "-50%" }}            animate={{ y: 0, x: "-50%" }}            exit={{ y: "100%", x: "-50%" }}            transition={{ type: "spring", damping: 32, stiffness: 360 }}            drag="y"            dragConstraints={{ top: 0, bottom: 0 }}            dragElastic={{ top: 0, bottom: 0.6 }}            onDragEnd={(_, info) => (info.offset.y > 110 || info.velocity.y > 600) && onClose()}          >            <div className="grab" />            {children}          </motion.div>        </>      )}    </AnimatePresence>  );}

Line notes:

  • The effect only runs while open (if (!open) return; returns undefined, which is fine).
  • Escape to close: keyboard users must be able to dismiss a dialog.
  • Scroll lock: body { overflow: hidden } stops the page behind from scrolling under your thumb. We save prev and restore it in the cleanup, so nested or other code's value survives.
  • L13[open, onClose] deps: if the parent passes a new onClose each render, the effect re-subscribes. That is correct, if slightly wasteful.
  • The scrim (the dimmed backdrop) closes on tap.
  • L22–23role="dialog" + aria-modal="true": assistive technology treats the rest of the page as inert while it's open.
  • L24–26x: "-50%" in every state: the sheet is centred with left: 50% in CSS plus a -50% translate. Motion owns transform, so the translate must be part of Motion's values. A CSS transform would be overwritten.
  • L24, 26y: "100%" → 0: slides up from just below the screen. Percentages are of the sheet's own height.
  • L27Spring damping: 32, stiffness: 360: snappy, with almost no bounce.
  • Drag to close:
    • drag="y" allows vertical dragging only.
    • dragConstraints={{ top: 0, bottom: 0 }} makes it spring back to 0 when released.
    • dragElastic={{ top: 0, bottom: 0.6 }}: it can't be pulled up at all (0), and downward drags follow at 60%, which feels like rubber.
    • onDragEnd: close if pulled more than 110 px or flicked faster than 600 px/s. (cond) && onClose() is a compact "if".
  • .grab: the little handle bar, a visual hint that the sheet can be dragged.

/** Segmented control with a sliding pill. */export function Segmented<T extends string>({  value,  onChange,  options,  id,}: {  value: T;  onChange: (v: T) => void;  options: { value: T; label: ReactNode }[];  id: string;}) {  return (    <div className="seg" role="tablist">      {options.map((o) => (        <button key={o.value} role="tab" aria-selected={value === o.value} className={value === o.value ?   • L2T extends string: works with any string union. In Study, Segmented<Mode> with value: Mode means onChange receives a Mode. Passing { value: "lsit" } is a compile error.

4.5 CountUp (lines 107–122)

TSX16 lines
/** Count up to a number (for scores). */export function CountUp({ to, duration = 1.1 }: { to: number; duration?: number }) {  const [n, setN] = useState(0);  useEffect(() => {    let raf = 0;    const start = performance.now();    const tick = (t: number) => {      const p = Math.min(1, (t - start) / (duration * 1000));      setN(Math.round(to * (1 - Math.pow(1 - p, 3))));      if (p < 1) raf = requestAnimationFrame(tick);    };    raf = requestAnimationFrame(tick);    return () => cancelAnimationFrame(raf);  }, [to, duration]);  return <>{n}</>;}
  • p clamps to 1 so the last frame lands exactly on to.
  • L5, 10, 12–13The raf id is kept so cleanup can cancel the loop if the component unmounts mid-animation. Otherwise setN would run on an unmounted component.
  • L1–2, 9, 14Restarts when to changes, a fresh count from 0.
  • Returns a fragment <>{n}</>: only text, no wrapper element, so the parent's <b> styles it.

  • Two circles: a faint full track, then the coloured progress on top.

  • L27strokeLinecap="round": rounded ends.

/** Coffee beans + sparks bursting out (celebration). */export function BeanBurst({ count = 26 }: { count?: number }) {  const [parts] = useState(() =>    Array.from({ length: count }, (_, i) => {      const a = (i / count) * Math.PI * 2 + Math.random() * 0.4;      const d = 110 + Math.random() * 120;      return {        x: Math.cos(a) * d,        y: Math.sin(a) * d - 40,        r: Math.random() * 540 - 270,        kind: i % 3, // 0 bean, 1 red spark, 2 cream spark        s: 0.7 + Math.random() * 0.6,        delay: Math.random() * 0.15,      };    })  );  return (    <div aria-hidden style={{ position: "absolute", left: "50%", top: "42%", pointerEvents: "none", zIndex: 2 }}>      {parts.map((p, i) => (        <motion.div          key={i}          style={{ position: "absolute" }}          initial={{ x: 0, y: 0, opacity: 1, rotate: 0, scale: 0.3 }}          animate={{ x: p.x, y: [0, p.y, p.y + 120], opacity: [1, 1, 0], rotate: p.r, scale: p.s }}          transition={{ duration: 1.6, delay: 0.5 + p.delay, ease: "easeOut" }}        >          {p.kind === 0 ?   • Particles computed once (useState(() => …), never updated), so re-renders don't re-randomise mid-flight.
  • Geometry: particle i of n gets angle ai​=n2πi​+ε with jitter ε∈[0,0.4) radians, and distance d∈[110,230) px. Its target is (dcosai​, dsinai​−40): evenly spread around a circle, nudged up by 40 px.
  • Keyframe arrays: y: [0, p.y, p.y + 120] goes out, then falls 120 px like gravity. opacity: [1, 1, 0] fades only at the end.
  • The bean is an ellipse plus an S-curve crease, drawn in SVG.
  • aria-hidden + pointerEvents: "none": decoration only, never blocks taps or confuses screen readers.

/** Deterministic warm colour for a player's avatar. */export function avatarColor(name: string) {  const palette = ["#f4eadb", "#ef3a42", "#e8b36b", "#c9d6a3", "#9fc7d8", "#e6a2b4", "#d9c2f0", "#f2c879"];  let h = 0;  for (const ch of name) h = (h * 31 + ch.charCodeAt(0)) >>> 0;  return palette[h % palette.length];} export const initials = (name: string) =>  name    .split(/[\s._-]+/)    .filter(Boolean)    .slice(0, 2)    .map((s) => s[0]!.toUpperCase())    .join("") || "?";
  • A string hash: h←(31h+code(ch))mod232. >>> 0 (unsigned right shift by zero) truncates to an unsigned 32-bit integer, so it never overflows into floats.
  • Deterministic: the same name always gets the same colour on every device, with no storage.
  • initials: split on spaces, dots, underscores and hyphens (the same characters names may contain), drop empty pieces, take the first two words' first letters. || "?" covers a name like __.

Bug journal

Clean run

The kit never broke during the build. Its pieces were written with the known pitfalls in mind, and the e2e tests exercise the sheet, switch, segmented control and ring on all 11 devices.

Foot-gun to know (did not happen here): a shared layoutId. If Segmented used one fixed layoutId (say "seg-pill") for every instance, Motion would treat all the pills as one element. With two segmented controls on screen at once, the pill would fly from one control to the other on every change. That is why Segmented takes an id prop and uses seg-${id}. Lesson: a layoutId is a global name, so make it unique per logical element.

Check yourself

Answer each one before you look. Multiple-choice questions mark your pick and let you try again; for open questions, answer aloud, then reveal and grade yourself honestly.

Q1
In Sheet, why must x: "-50%" be in initial, animate and exit?
Did you have it?
Motion writes the whole transform. If x isn't part of its values, the CSS translateX(-50%) centring is overwritten and the sheet jumps right by half its width.
Q2
The ring for 50/100 with size 190, stroke 14: what is the offset?
Did you have it?
C=2π⋅88≈552.92, so the offset is C(1−v)=552.92×0.5≈276.46.
Q3
Why does BeanBurst compute particles in useState(() => …) instead of in the render body?
Did you have it?
Render can run many times; recomputing would re-randomise targets mid-animation and make particles jump. The lazy state runs once.
Q4
What breaks if CountUp doesn't cancel its animation frame on unmount?
Did you have it?
The loop keeps calling setN on an unmounted component: wasted work, and a warning in older React.
Q5
Two players named "Ana" and "Ben": can they get the same avatar colour?
Did you have it?
Yes. With 8 colours, collisions are common (about a 1-in-8 chance for any pair). It's decoration, not identity.

Flashcards

See all 8 cards as a listfor a quick scan
  1. Formula for the ring's dash offset?
    offset = C·(1 − v), with C = 2πr and r = (size − stroke)/2.
  2. Why rotate the ring SVG −90°?
    SVG strokes start at 3 o'clock; rotating starts the progress at 12.
  3. Ease-out cubic formula?
    e(p) = 1 − (1 − p)³.
  4. When does the sheet close on drag end?
    Offset > 110 px or downward velocity > 600 px/s.
  5. Why per-instance layoutId in Segmented?
    Equal layoutIds are treated as one element; two controls would share and fling one pill.
  6. What role and attribute make a toggle accessible?
    role="switch" with aria-checked on a real button.
  7. What does >>> 0 do in the hash?
    Truncates to an unsigned 32-bit integer.
  8. Why does useToast return as const?
    To type the result as a tuple, so destructuring gets precise types.
